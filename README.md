# 从Buffon投针到Laplace：几何概率与蒙特卡洛模拟的历史演进

本项目探讨了 18 世纪至 19 世纪初几何概率（Geometric Probability）的发展脉络，重点梳理了 **Buffon (1777)** 的投针问题与 **Laplace (1812)** 在《概率分析论》中利用随机实验反推 $\pi$ 值的思想推导，并结合现代 Python 数据分析手段进行了数值模拟与验证。

---

## 📌 项目亮点

* **历史文献复现**：整理并解读 1733年/1777年 Buffon 及 1812年 Laplace 的原始数学推导过程。
* **Python 蒙特卡洛模拟**：基于 NumPy / Matplotlib 复现投针实验。
